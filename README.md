# 🕊️ Programadores para la Paz

> **“La tecnología, cuando nace desde la comunidad, se convierte en herramienta de transformación.”**

Bienvenido/a a este espacio de aprendizaje, código y conciencia.  
Aquí no solo se aprende a programar: se construyen las bases para que las comunidades puedan crear sus propias soluciones tecnológicas, libres, abiertas y con sentido social.

---

## 🌱 ¿Qué es este proyecto?

Este repositorio documenta un camino formativo práctico en **Node.js, Express, Git y GitHub**, donde cada semana se da un paso más hacia el dominio de las herramientas que permiten construir servidores, APIs y sistemas de información comunitaria.

Desde el primer `git commit` hasta la creación de endpoints para reportes ciudadanos, **cada carpeta es un peldaño hacia la autonomía tecnológica**.
